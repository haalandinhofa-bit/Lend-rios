# Lendários — Minecraft 1.21.4

Mod NeoForge para Minecraft Java 1.21.4.

## Comando

Use **`/lendario`** ou **`/Lendario`** para receber uma shulker preta chamada **Caixa dos Lendários**, com 13 relíquias.

## Relíquias

1. Bota do Vento — velocidade.
2. Batata Saltitante — salto aprimorado.
3. Bússola do Lar — mostra as coordenadas do ponto inicial do mundo.
4. Capacete das Marés I — respiração aquática.
5. Capacete das Marés II — nado aprimorado.
6. Amuleto Solar — resistência ao fogo.
7. Lampião Luminoso — visão noturna.
8. Pena Flutuante — queda lenta.
9. Picareta Construtora — mineração rápida.
10. Relógio da Aurora — regeneração.
11. Relógio do Crepúsculo — sorte.
12. Medalhão da Fortuna — aumento temporário de vida máxima.
13. Mapa do Explorador — mostra suas próprias coordenadas.

As habilidades desta edição são utilitárias e afetam somente quem usa o item. Ela não implementa as habilidades de combate da série.

## Requisitos

- Minecraft Java Edition 1.21.4
- NeoForge 21.4.161
- Java 21

Coloque o arquivo `lendarios-1.0.0.jar` na pasta `mods`.

## Compilar

Com Gradle 8.12+ e Java 21:

```bash
gradle build
```

O JAR será gerado em `build/libs/`.

O GitHub Actions compila o projeto a cada push e publica o JAR como artefato na execução do workflow.
