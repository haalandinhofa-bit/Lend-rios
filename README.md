# Lendários — reconstrução em andamento

## Objetivo
Este projeto está sendo reconstruído para substituir a versão 1.0.0, que usou habilidades diferentes das solicitadas.

A nova implementação seguirá as mecânicas documentadas dos Itens Lendários da Creative Squad 4, usando itens-base do Minecraft com comportamento especial.

> A versão anterior não deve ser considerada a versão final.

## Comando
`/lendario` entrega uma shulker preta com a coleção de itens.

## Estado
Reconstrução e validação das mecânicas em andamento.
